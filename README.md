# Library - The Odin Project

Welcome to the Library project, built as part of The Odin Project's Full-Stack JavaScript Curriculum. This project focuses on practicing JavaScript objects, constructors, and DOM manipulation by creating an interactive digital book-tracking application.

## 🎯 Project Overview

The Library app enables users to track their personal collection of books for the current session. Users can input details about books they have read or wish to read, display them in a structured table layout, and interact dynamically with the list.

## Key Features

- Add New Books: A form letting users input book details such as title, author, page count, and read status.

- Dynamic Table Display: Dynamically renders and displays all saved books in a clean table format using JavaScript DOM manipulation.

- Toggle Read Status: Each book entry includes a button to easily switch its status between "Read" and "Not Read yet".

- Delete Functionality: A dedicated delete button for each row to instantly remove a book from the collection.

- In-Memory State Management: Manages the collection using a JavaScript array of objects, keeping data light and session-based.

## 🛠️ Built With

- HTML5: Semantic markup for page structure, data table layout, and input forms.

- CSS3: Modern styling for a clean, responsive book catalog interface.

- JavaScript (ES6+): Core application logic, including object constructors/classes, array methods, event listeners, and dynamic DOM rendering.
